# CCF6 Domain Language

CCF6 is an experimental vocabulary for testing Neurocognitive Linguistics as a physical, relational account of language and cognition.

## Network organization

**Network**:
The complete connected cognitive system in which local functions arise from connectivity and activity.
_Avoid_: processor, symbolic system

**Column**:
The smallest addressable processing population, whose specific function is determined by its connections and activation history rather than stored symbolic content.
_Avoid_: symbol, concept cell, node, neuron

**Population**:
A group of Columns receiving a related class of evidence and participating in one or more distributed functions.
_Avoid_: center, symbolic module, Space

**Functional Web**:
A distributed, overlapping coalition demonstrated by repeatable co-activation, effective internal connectivity, completion from independent Entry Routes, and causal lesion effects.
_Avoid_: activation-threshold set, object store, singleton Web, encapsulated concept

**Subweb**:
A functionally distinguishable part of a Functional Web that can also participate in other webs.
_Avoid_: owned component

**Available Column**:
A Column whose plasticity has not yet been committed to a recurring function.
_Avoid_: empty node, unused symbol

**Recruited Column**:
A Column measurably entrenched by repeated successful participation in a recurring activity pattern.
_Avoid_: concept, Cardinal Node

**Cardinal Candidate**:
A Recruited Column or redundant population that converges across predefined entry routes into one Functional Web.
_Avoid_: committed winner, proven cardinal

**Cardinal Node**:
A Cardinal Candidate that demonstrates stable access, partial-cue Ignition, supporting-subweb reactivation, lesion sensitivity, and redundancy behavior while its represented content remains distributed.
_Avoid_: grandmother cell, concept container, Hub

**Modality**:
The sensory or motor channel through which activity enters or leaves a Population, such as visual, auditory, tactile, motor, or affective.
_Avoid_: cognitive function

## Activity and learning

**Activation**:
The graded current response of a Column or population to excitation, inhibition, recurrent state, and context.
_Avoid_: truth value, symbolic presence

**Competition**:
Mutual inhibition among alternatives that sharpens which Columns participate in the current activity pattern.
_Avoid_: global winner selection

**Persistence**:
Temporary maintenance of activation through recurrent connectivity.
_Avoid_: permanent memory

**Eligibility**:
A temporary local trace marking connections whose co-activity may be strengthened if a later Success Signal arrives.
_Avoid_: weight change, global error

**Success Signal**:
A diffuse modulatory event indicating that the current network activity achieved an experimentally observable outcome, without assigning credit to individual connections.
_Avoid_: gradient, semantic label, local winner

**Recruitment**:
The experience-dependent commitment of Available Columns through eligible connections repeatedly confirmed by Success Signals.
_Avoid_: object creation, label assignment, competition win

**Entrenchment**:
Increasing stability and accessibility caused by repeated successful use of network pathways.
_Avoid_: one-shot storage

**Ignition**:
Coordinated activation of a Functional Web from a sufficiently informative partial route.
_Avoid_: lookup

**Pattern Completion**:
Reactivation of absent parts of a learned Functional Web from partial evidence.
_Avoid_: record retrieval

**Entry Route**:
A functionally independent sensory, linguistic, conceptual, or motor path capable of contributing to a Functional Web's Ignition.
_Avoid_: duplicate cue

**Target Basin**:
The stable distributed activity approached by recurrent settling during a full learned Presentation.
_Avoid_: category label, stored vector

**Lesion**:
An experimental intervention that prevents selected Columns from broadcasting while preserving observation of activity reaching them.
_Avoid_: deletion, retraining

## Experimental apparatus

**World**:
The external arrangement presented to the network during an experiment.
_Avoid_: internal model

**Object**:
A presentation target defined by a configuration of externally observable parts.
_Avoid_: stored concept

**Presentation**:
One ordered exposure of an Object to the network.
_Avoid_: representation

**Sample**:
One sensory observation within a Presentation.
_Avoid_: network state
