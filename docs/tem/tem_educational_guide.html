A plain-English, visual introduction

How can a brain reuse what it has learned?

The Tolman–Eichenbaum Machine, or TEM, begins with a practical puzzle: experiences change, but their underlying relationships often stay the same. TEM shows how sequences can build a reusable cognitive map and rapidly connect that map to each new situation.

Observe a sequence

The learner sees an object, takes an action, sees another object, and repeats. It is never handed a complete map.

Predict what comes next

Not only physical space. A “world” can be a room layout, an ordered list, a social hierarchy, or any situation expressible as states connected by relations. For example, A > B > C has an ordered transition structure even though nobody is walking through it.
02 · Key concept

What is a transition structure?

A transition structure is the pattern of possible changes from one state to another. It describes how positions are connected, without saying what sensory item appears at each position.

04 · Updating position

Path integration: keeping track as you move

Path integration is TEM’s way of answering “where am I now?” Starting from its previous structural state g, the model applies each action or relation in sequence to produce its next state—without first looking up a complete external map.

The everyday idea: dead reckoning. If you close your eyes, take two steps east and one north, you can estimate where you are relative to where you began. TEM uses the same principle, but its “position” is a pattern of neural-network activity and its “step” can be any learned relation—not only physical motion.

Read the equation in words

Take the current population pattern gt; transform it with the learned weights Wa selected by the current action; then pass the result through a nonlinear activation σ. The result is the predicted structural state at the next step.

This is the compact TEM/TEM-t description used for teaching. The full TEM inference model also combines this transition estimate with memory-derived sensory evidence.

What must the model learn?

separation

Different states need different codes

If two locations had indistinguishable g patterns, TEM could not reliably attach and retrieve different memories at them.

consistency

The same state needs the same code

Returning to one node by a new route should recover the same g pattern, so the memory stored there remains addressable.

composition

Relations must combine correctly

A sequence of action-dependent updates should represent the endpoint implied by the learned transition structure, including routes never taken before.

TEM generalizes path integration beyond physical space

2-D environment

Position by movement

g is updated by north, south, east, or west. After a sequence of moves, it acts as an internal address for a room or graph node.

Ordered sequence

Position by succession

“Next” repeatedly advances g through list positions. The model can track an abstract place in an episode or repeating lap cycle.

Relational graph

Position by typed relation

Actions such as parent, child, or sibling transform g according to learned graph rules. No literal body needs to move.

Why this enables inference

Suppose TEM has visited a destination before, but now reaches it by a route it has never traveled. If the action updates compose correctly, path integration produces the destination’s familiar g code. That code can query associative memory for the sensory item stored there. Thus path integration says where; memory says what is there.

Connection to grid-like responses

Learning a g code that separates different locations yet returns to the same pattern at the same endpoint places strong constraints on the recurrent representation. In 2-D tasks, TEM finds that grid- and band-like structural responses can emerge under these pressures.

Connection to transformers

The 2022 TEM-t paper interprets path-integrated g as a learned positional encoding. Unlike a fixed token index, it reflects the actions taken and therefore the structure of the sequence or graph being traversed.

Movement estimates drift; memories can correct them

Small recurrent errors accumulate across many updates. TEM therefore does not have to trust dead reckoning alone: a familiar sensory observation can retrieve candidate structural codes from associative memory and refine the path-integrated estimate.

Why the path estimate still matters

A sensory cue may be ambiguous: several rooms may look alike. The recent action history narrows down which matching memory is plausible.

Why sensory correction matters

A distinctive landmark can pull a drifting internal estimate back toward a previously stored address, much as recognizing a building corrects uncertain dead reckoning.

What TEM is—and is not—given. During these tasks the model receives a sensory observation and the action/relation that caused each transition. It is not given an x–y coordinate or the full graph. Across training environments, slow learning shapes the shared action-dependent weights so that g comes to encode useful transition structure.
05 · Memory

What is an associative memory?

An associative memory stores linked features together, so that presenting part of the pattern can bring back the rest. It is the computational version of remembering a whole episode from a partial clue.

Association

Structural code g and sensory code x are active together. Their conjunction p represents “what–where.”

Fast weights

TEM stores p using rapidly changing Hebbian connections: roughly, “cells active together strengthen their link.”

Pattern completion

A partial, noisy cue settles toward the nearest stored complete pattern, reinstating missing information.

Two learning speeds. Slow network learning discovers reusable transition rules over many worlds. Fast associative learning stores the particular contents of the current world. This separation helps TEM both generalize and remember specifics.
06 · Cognitive maps

A cognitive map is more than a map of a room

In these papers, a cognitive map is an internal organization of knowledge. It says which meaningful states exist, how they relate, and what may happen next. Physical space is the easiest example—not the definition.

A cognitive map is not necessarily: a picture, a complete copy of the world, an x–y coordinate system, or a store of rewarded routes. It can organize a family, a sound-frequency task, accumulated evidence, a recipe, or progress through a four-lap cycle.

The hidden-state problem: the same view can mean different things

A sensory observation alone often fails to identify the current state. This is called sensory aliasing. Two places may look identical but lead to different futures; the same central corridor of a T-maze may mean “next turn left” on one trial and “next turn right” on another.

Latent means inferred, not directly seen

A latent state is the model’s best explanation of where it is in the task. It may combine current sensation, recent history, action, physical location, and task progress. Splitting one repeated observation into several hidden states lets the map predict the correct future in each context.

The two frog observations look the same. Their neighbors and action histories differ. A learner trained to predict what comes next is pressured to assign them different latent states and connect those states correctly.

Learning can happen before reward

By predicting sensory sequences, the system can learn useful state structure while simply exploring. Later, when a reward or goal appears, the map is ready to support behavior. This is a computational account of latent learning.

Map quality is task-relative

The “correct” state is not every fact about the universe. It is an abstraction sufficient to predict relevant futures and choose actions. Different tasks may require different state boundaries.

Global bases

Grid-like codes describe relational position throughout a space. Their shared rules can transfer as a whole.

Local bases

Border-, object-, and goal-vector-like codes describe position relative to one reusable feature.

Conjunctions

Why factorization helps. If “where is the oven?” and “what step of the recipe?” are represented separately, the recipe can transfer to a new kitchen. The current episode still needs to bind the abstract step “go to oven” to this kitchen’s oven location.

A map can make planning cheaper

Search-heavy solution

With only node identities, finding a route may require expanding alternatives step by step.

Representation-heavy solution

Coordinates, grid/vector codes, predictive maps, or prelearned policies can place useful relational computations inside the representation itself.

“Solve it in the representation”

A clever state code can reduce online search. SR-like maps make value calculation easier; grid-like codes support vector operations; prelearned goal-vector codes can carry a useful action policy into a new environment. The map does not eliminate every planning problem, but it can move expensive work into prior learning.

The map may include time and levels of abstraction

time in task

Time cells as progress

During a delay, physical position is fixed but task position changes. Sequential “time-cell” activity may represent progress toward the delay’s end because that progress predicts the future.

temporal context

Drift as temporal remapping

If hippocampal cells bind space × sensation × time, changing the time code can change the conjunctive population while spatial structure remains stable. The review offers this as a possible explanation of representational drift.

hierarchy

A task map above a spatial map

A prefrontal-like code for “next, go to the oven” could contextualize an entorhinal spatial map. Hippocampal memory could bind that abstract task step to the oven in this particular kitchen.

When pieces stay separate

If goals, rooms, and task rules are frequently recombined, pressure for transfer favors clean factorized bases: space here, goal there, task stage elsewhere.

When pieces become entangled

If one configuration repeats for a long time, a bespoke representation may be more efficient and precise. Grid patterns can warp toward stable goals rather than remain perfectly factorized.

The broad development beyond the original TEM result. TEM supplied a concrete mechanism for learning reusable structure and grounding it with fast memories. The cognitive-map review places that mechanism inside a larger toolbox: latent-state discovery, predictive graph representations, compositional bases, reinforcement learning, replay, time, and hierarchical task maps. Some links summarize established model results; others are explicit hypotheses for future experiments.

10 · Deep dive

From one neuron to a population code

To understand grid cells, keep two places separate: the neuron is physically in the entorhinal cortex; its firing field is a region of the external arena in which that neuron tends to fire strongly. A rate map draws neural activity over arena coordinates—it does not draw neurons scattered around the arena.

The single most important reading rule: every bright patch in one rate map is a location in the world, not a cell. If one map has twenty bright patches, it can still describe the activity of just one recorded neuron as the animal visits twenty different regions.

4. How a population can register location

No single grid cell identifies a unique position: neuron A fires at every blue field. Instead, the brain can use a population activity vector—the simultaneous firing levels of many cells with different phases and scales. Each location produces a characteristic combination.

Why phases help

Neuron A is high near blue peaks.

Neuron B samples the gaps because its whole lattice is shifted.

Cells at different phases respond differently at the same location. Together they avoid leaving the arena represented by only one repeating lattice.

Why multiple scales help

Fine module repeats often.

Coarse module repeats less often.

A pattern that repeats in one module usually does not repeat at exactly the same places in every other module. Combining modules greatly enlarges the range over which the population code is distinctive.

What “registering location” means here: the selected location is represented by a distributed pattern such as [A high, B low, D medium, …; C medium, F high, …], not by assigning that location to one dedicated grid cell. Downstream circuits can learn to interpret this joint pattern, and TEM’s g representation uses such structural activity to address memories.

Teaching vector versus a real experimental vector

The diagram uses only 14 simulated cells, so its location vector has 14 entries. This is intentionally small enough to read. In real experiments, researchers may analyze tens to hundreds of spatially tuned cells from an animal; for scale, Stensola et al. (2012) reported datasets containing up to roughly 186 grid cells from an individual animal across recordings. A vector made from 186 cells would have 186 simultaneous activity values—often estimated as spike counts or firing rates over a short time window—rather than the fourteen bars shown here. The complete biological population involved in representing location is almost certainly much larger, potentially involving thousands of entorhinal neurons across several modules, but experiments record only a sample of it and not every recorded neuron is a grid cell. Therefore, “186 dimensions” illustrates the magnitude of a substantial experimental dataset, not a known fixed size for the brain’s full location code.

Also note that cells collected across separate recording periods cannot literally form one simultaneously measured vector. Modern large-scale probes can measure many neurons at once, but the size and composition of the complete functional population remain uncertain.

A simple analogy

Nobody tells a delivery driver to draw a map using “main roads,” “dead ends,” and “landmarks.” If the driver repeatedly tries to predict efficient routes, these useful categories naturally appear in the driver’s mental organization. Likewise, TEM’s hidden units organize around regularities that help prediction.

Change the experience, change the useful pattern

Random movement in open 2-D spaceTranslation is regular in every direction → periodic grid- and band-like bases are useful.

Binding content to structureEach world has different sensory arrangements → particular place- and landmark-like memories form.
Emergent does not mean “without assumptions.” TEM already has an architecture, a prediction objective, recurrent updates, separate g/x variables, associative memory, and a training distribution. These are strong learning biases. The narrower claim is that explicit grid, border, or place-cell templates are not supplied as targets.
12 · Beyond space

What are “laps,” and why do they matter?

A lap is one complete circuit around a track. In a key task, an animal runs repeatedly around a circular track but receives a recurring event or reward only every fourth lap. Physical position repeats each lap, yet the task state does not.

Four-lap cycle
Place-like

Fires at one track position on every lap.

Lap-selective

Fires there only on, say, lap 2.

Counting-like

Activity rises or falls with lap number.

The lesson

“Where am I?” can mean two things simultaneously: position on the physical track and position in the abstract four-lap cycle. TEM therefore treats location as a state in the task’s transition graph, not only an x–y coordinate.

Why reward is in quotation marks in the model. Computationally, it can simply be a distinctive sensory event repeating every four circuits. That periodic event reveals that four visually similar laps occupy different relational states.
13 · Change

Remapping, in plain English

Remapping occurs when the spatial firing pattern of a place cell changes between environments or contexts. A cell active near the door in Room A may become active near the opposite wall in Room B—or become silent.

Environment A
🌳☕

One place-like p unit has a field in the upper-right region.

→
Environment B · sensory cues rearranged
🚲🍎

The same p unit now has a field elsewhere: it has remapped.

g

Structure can remain stable

Grid-like relations and phases provide a reusable structural basis across worlds.

x

Content changes

Objects and sensory cues occupy different positions, changing which x inputs coincide with g.

p = g × x

Conjunction relocates

Because p needs compatible structural and sensory input, its place field can move.

Apparently random does not mean completely unconstrained

TEM predicts that a remapped place field is more likely to appear at a location compatible with its entorhinal grid input—for example, another peak of the relevant grid phase. Simultaneous place/grid recordings analyzed in the 2020 paper supported this hidden statistical relationship. It is a constraint, not a claim that remapping is perfectly predictable from one grid cell.

14 · Put together

The complete narrative in one page

From raw sequences to cognitive maps, memories, flexible behavior, and observed response patterns, the argument follows a single chain.

Infer useful states

Observations can repeat, so sequence context separates hidden states that predict different futures.

Abstract structure

Path-integrated g captures reusable transition rules while factorized bases make maps compositional.

Ground with memory

Bind structural g and sensory x into fast, particular memories p for the current world.

Use the map

Predict, infer, plan, transfer policies, learn new content quickly, and explain diverse neural responses.

Check your understanding

Which cell type is newly predicted by the cognitive-map review?

A contextually modulated, or route-dependent, goal-vector cell: it should point toward a goal only when that goal is relevant at the current stage of the task. The other added cards mostly organize previously recorded cell types or TEM-like model responses.

Is a cognitive map necessarily a spatial map?

No. It is an organization of useful latent states and relationships. Physical location, family position, sensory evidence, lap number, time in a delay, and task stage can all be map dimensions.

Why can’t the current sensory observation always define the current state?

The same observation can occur in situations with different histories and futures. A sequence learner must infer distinct latent states to remove this sensory aliasing.

How do CSCG and TEM complement one another?

CSCG can rapidly discover a hidden graph for a new experience but normally learns each graph anew. TEM slowly learns reusable cortical structure, then rapidly grounds it with hippocampal memories. The review proposes that a biological system may use both capabilities.

Does path integration mean TEM memorizes a route?

No. It repeatedly updates an internal structural state using each action. If the learned transition rules are consistent, different valid routes to the same endpoint can recover the same g code.

Why combine path integration with sensory memory?

Action-based estimates can accumulate error, while sensory cues can be ambiguous. Together, the path estimate helps disambiguate repeated cues and familiar cues help correct drift.

Is each dot in a grid pattern a different cell?

No. In a rate map for one grid cell, all repeating peaks belong to that same cell. A population contains many such cells with different phases and, across modules, different scales.

Does “phase” mean the cell fires periodically in time?

Not here. Spatial phase is the translation of the entire firing lattice in two-dimensional space. Temporal rhythms are a separate issue.

Why do place-like cells remap while grid-like structure generalizes?

Grid-like g units represent reusable transition structure. Place-like p units conjoin that structure with sensory x, which differs between environments.

Why can border and object-vector patterns emerge from the same objective?

Both can improve next-state prediction under different movement statistics. Walls and approached objects systematically affect likely future transitions.

Glossary

Technical terms, translated

Short definitions for the vocabulary used throughout this guide.

Abstraction

Keeping the common relational rule while ignoring details that vary from case to case.

Action-dependent transition

An internal-state update selected by the action or relation taken—for example, east versus north.

Associative memory

A store that retrieves a complete learned pattern from a related or partial cue.

Basis function

One component in a set of response patterns that can be combined to represent richer states.

Cognitive map

An internal organization of useful states and their relationships that supports prediction, inference, planning, and flexible behavior; it need not be spatial.

Clone-structured cognitive graph (CSCG)

A model that assigns multiple hidden “clone” states to repeated observations and learns their transitions from sequence context.

Composition

Building the current state representation by combining reusable pieces such as spatial, boundary, object, goal, or task codes.

Conjunction

A representation active for a particular combination of features—here, structural g together with sensory x.

Edge / transition

A possible move or relation connecting two graph states.

Emergence

An organized property that appears through learning rather than being explicitly supplied as a target template.

Factorization

Representing separable aspects—structure and content—independently so they can be recombined.

Firing field

A region of a task or environment where a neuron is especially active.

Generalization

Using learned knowledge correctly in a new situation.

Graph

A mathematical description made of states (nodes) and connections (edges).

Hebbian learning

Strengthening a connection when connected units are active together; a mechanism for rapid association.

Latent learning

Learning useful environmental structure during unrewarded experience, before that knowledge is needed for a goal.

Latent state

An unobserved situation inferred from current input, history, and actions so that distinct futures can be predicted.

Module

For grid cells, a population with approximately shared grid scale and orientation but varying phases.

Node / state

One location or situation in a graph.

Path integration

Updating estimated position by accumulating movements or relational transitions.

Pattern completion

Recovering a complete stored memory from incomplete or noisy input.

Prediction error

The difference between what the model predicted and what it actually observed; learning reduces it.

Rate map

A plot of average neural/model-unit activity against position or task state.

Replay

Offline reactivation of state sequences; the review proposes it may help construct and compose maps as well as reinforce memories.

Remapping

A change in place-cell firing locations or activity when the environment or context changes.

Sensory aliasing

When the same observation occurs in multiple hidden states that have different relationships or futures.

Spatial phase

The two-dimensional offset of a grid cell’s complete firing lattice.

State abstraction

Keeping dimensions relevant to behavior and prediction while discarding details that need not alter the state.

Successor representation (SR)

A predictive graph code summarizing discounted future state occupancy under a behavior policy.

Transition statistics

Regularities in how frequently and in what ways states follow one another under a behavior policy.

Transition structure

The reusable pattern of possible state changes, independent of the sensory identity attached to each state.

Zero-shot inference

Correctly inferring a relation or transition that was not directly experienced in the current world.
