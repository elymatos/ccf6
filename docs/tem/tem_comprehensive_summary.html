01 · Thesis

One computation across space and relations

A room, a family tree, an ordered list, and a four-lap reward schedule can all be represented as graphs: states are nodes; actions or relations are typed edges. TEM learns regularities in how those edges transform an internal state.

Problem

Prediction

Given previous observations and the action/relation just taken, predict the next sensory observation. The model sees sequences—not the hidden graph.

Abstraction

Factorization

Separate reusable transition structure from arbitrary sensory identities. “North” has the same relational meaning whether a location contains a cat, chair, or banana.

Benefit

Generalization

Once structure is known, visiting each node can suffice; every edge need not be experienced. This supports zero-shot shortcuts and first-presentation inference.

The learning objective: reduce error in predicting sensory observations. Grid, band, border, object-vector, place, and landmark-like responses are not labels supplied to TEM. They are patterns observed afterward when researchers plot learned unit activity against location or task variables.

Position fingerprint
Important precision. A biological module contains many grid cells sharing approximately the same spacing and orientation but differing in spatial phase. Here, each lattice displays one representative phase from each scale module. The highlighted peak does not mean a different cell owns every vertex: all peaks in one lattice are repeated fields of the same example cell. A complete population code combines activity levels across many phases and modules.

Scale / spacing

Distance between neighboring firing-field centers. Modules have discrete scales; the visualization uses three for clarity, not because biology is limited to three.

Spatial phase ≠ time phase

Phase is the 2-D translational offset of a lattice. It says where peaks occur. Grid firing can also be modulated by theta rhythms, but that is a separate temporal phenomenon.

Lap-selective, event-specific & counting-like cells

On a circular track rewarded every fourth lap, TEM reproduces hippocampal units that code track position every lap, units selective for one lap in the four-lap cycle, and units varying with lap number. MEC-like g units represent both physical position and the abstract four-lap state. This shows that “location” means position in a learned task graph—not necessarily Euclidean coordinates.

context, not a core TEM result

Head-direction & speed cells

Biological navigation also includes direction- and speed-tuned populations. Action/direction enters TEM’s transition operator, but the 2020 results emphasized grid, band, border, object-vector, place, landmark and task-state responses; TEM should not be read as a complete taxonomy of the hippocampal formation.

05 · Learning

Why distinct response patterns emerge

The model is optimized for accurate prediction while memories must remain distinguishable and retrievable. Change the experienced transition statistics, and the useful basis changes.

“Emergent” does not mean architecture-free. TEM’s factorization, recurrent dynamics, parallel streams, Hebbian memory, activation functions, training distribution and loss all provide inductive biases. The claim is that bespoke cell templates are not programmed.

06 · Memory

Remapping looks random—but retains structure

Grid-like g codes generalize across environments. Place-like p codes bind g to a different sensory arrangement in each environment and therefore relocate. TEM predicts that relocation remains constrained by grid phase.

MEC

Stable relation

A grid cell tends to retain frequency; phase relationships among cells in a module remain correlated across environments.

HPC

Global remapping

Place fields change position because conjunctive sensory inputs differ, so neighbor relations are much less preserved.

Prediction confirmed

Hidden constraint

A place cell co-active with a grid cell should remap preferentially to another peak compatible with that grid phase.

Whittington et al. tested simultaneous place/grid recordings in two independent datasets. Grid activity at place-field peaks correlated across environments beyond shuffled remappings. The reported conservative-set correlations were r = .322 (115 pairs) and r = .273 (64 pairs), supporting non-random structural constraints—not perfect determinism.
07 · ICLR 2022

TEM and transformers are mathematical cousins

Whittington, Warren & Behrens show that TEM’s associative retrieval resembles self-attention, while its path-integrated g state behaves like a learned recurrent positional encoding.

Transformer attention

retrieve values weighted by query–key similarity

Keys / queries

Derived from recurrent position encodings g, so attention asks: “Which past experience occupied this relational position?”

Values

Derived from sensory observations x. Matching positions retrieve associated content: “What did I observe there?”

Position is learned

Instead of fixed sine/cosine sequence indices, et+1 = σ(etWa) learns position in the task’s transition structure.

TEM-transformer (TEM-t): a causal transformer with recurrent action-dependent position encodings learned grid- and band-like representations, was substantially more sample/time efficient in the authors’ comparison, and scaled to more memories. Sparse “memory neurons” in a biologically interpreted attention implementation showed place-like tuning and remapping.

The argument is stronger than “both happen to produce grid cells”: the papers derive a formal correspondence between Hopfield-like associative retrieval and attention. It is still a computational analogy, not evidence that the brain literally implements a standard digital transformer or backpropagation.

08 · Outlook

Predictions, implications & boundaries

TEM is best treated as a unifying computational hypothesis that generates experiments—not a settled one-to-one map of all entorhinal–hippocampal anatomy.

Cross-environment remapping is constrained

Place fields should preserve relationships to one or more grid modules even when their absolute positions change.

Non-spatial remapping preserves task phase

A cell selective for lap 2 should remain lap-2 selective after spatial remapping when sensory events repeat each lap.

Entorhinal cells encode nested task state

In the four-lap task, MEC should contain both spatial periodicity and representations of position in the abstract four-lap cycle.

General cell responses follow transition statistics

Manipulating policies, objects, boundaries or graph rules should systematically reshape the learned basis.

Beyond physical space

The same machinery can represent ordinal, social, conceptual or grammatical “location” whenever reusable typed transitions exist.

EC–neocortex bridge

Learned structural coordinates may index distributed cortical content; hippocampal memory rapidly binds and reinstates those factorized representations.
