# Contrast is not the sensory input code

Status: accepted · 2026-09-08

Contrast was removed from the sensory path because it varied with an Object's distance from the World frame and also acted as drive magnitude, allowing position to alter every sensory Population. Stateless adapters now encode what is sampled at unit strength; contrast remains available only as an external analysis and sampling heuristic.

## Consequences

The sensory boundary performs transduction without carrying presentation history or assigning learned function. Local relations, categories, and invariances must arise downstream through connectivity and learning rather than being installed by the input representation.
