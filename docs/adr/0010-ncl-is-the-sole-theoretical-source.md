# NCL is the sole theoretical source

Status: accepted · 2026-09-09

CCF6 now derives its cognitive terminology, architecture, specifications, experiments, and implementation solely from Neurocognitive Linguistics as summarized in `docs/neurocognitive_linguistics_summary.md`. The previous synthesis imposed separate structural and binding processors that were not required by that theory; they were removed rather than renamed so future experiments test distributed Functional Webs, cardinal convergence, reciprocal activation, competition, and local recruitment directly.

## Consequences

Git history remains intact, but the current tree contains no documentation or runtime support for the abandoned synthesis. Tooling that is theoretically neutral—the Python/Laravel process seam, artifact format, sparse numerical connections, and workbench—remains available for the restarted experiments.
