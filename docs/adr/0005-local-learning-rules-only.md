# Local learning rules only

Status: accepted · 2026-09-07

CCF6 changes network connectivity only from information locally available at a connection: presynaptic activity, postsynaptic response, competition outcome, and local plasticity state. This follows NCL's developmental account of successful co-activation and recruitment; global gradients and externally assigned semantic labels would answer a different scientific question.

## Consequences

A negative result may show that the current local rule is inadequate rather than that the target behavior is impossible. Every learning experiment therefore requires an untrained baseline and direct measurements of the behavior learning was intended to change.
